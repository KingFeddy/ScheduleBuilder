## Refreshing this dataset

From `apps/api`, collect complete term snapshots with `python -m scripts.collect_offering_history --terms <term codes> --output <snapshot directory>`. Then run `python -m scripts.analyze_offering_history --snapshots <snapshot directory> --output src/data/course_offering_history.json --report <report path>` with matching `--baseline-start`, `--recent-start`, and `--latest-term` boundaries. Use a new snapshot directory to refresh previously collected terms. Collection is read-only and does not import historical sections into the live database.

The planner reads the bundled dataset. Updating live seat counts does not refresh this history; regenerate and redeploy it when a new term becomes available. Explicit confirmed offering rules take precedence.
